# README icons

These icons are from [Heroicons](https://github.com/tailwindlabs/heroicons) v2.2.0 (24px outline set), by Tailwind Labs, used under the MIT License. The licence text is in [LICENSE](LICENSE).

The only change is the stroke colour: `currentColor` is replaced with a fixed purple (`#8466a8`), because an SVG shown through an `<img>` element cannot inherit the page's text colour and would otherwise render black on GitHub's dark theme. The icons are decorative and sit next to text labels.
